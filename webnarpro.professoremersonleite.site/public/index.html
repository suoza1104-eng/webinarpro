Ajuda

Perguntas frequentes sobre o WebnarPRO.

Como o webinar "ao vivo" funciona sem travar com muita gente?

O vídeo é entregue por uma CDN especializada — o mesmo mecanismo que serve vídeos do YouTube — então cada espectador baixa o arquivo de forma independente. O chat simulado roda inteiramente no navegador de cada pessoa, sem gerar carga no seu servidor. Veja o Simulador de Custo para estimar o valor real.

Este é um protótipo navegável — nada aqui é salvo em um banco de dados real.

Toda interação (criar webinar, adicionar usuário, mensagens de chat) fica guardada apenas no seu navegador, para você simular o fluxo completo antes de decidirmos construir a versão real com backend.
